git diff HEAD~2 compares the current worktree with the commit reached by
following the first parent of HEAD twice. Here HEAD~2 is the initial
"Add student details" commit, so the diff shows the net change since it:
the additional course line. Without a path argument, it covers all tracked
files; any uncommitted worktree changes would also appear.
