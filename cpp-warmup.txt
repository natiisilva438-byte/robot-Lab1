Operators

Numbers
1. All four are signed integer types by default. Their guaranteed minimum widths are short 16 bits, int 16 bits, long 32 bits, and long long 64 bits. Exact widths are implementation-dependent; short <= int <= long <= long long in range/precision.
2. double generally has greater precision and range than float; the standard guarantees at least as much precision. Converting 3.14 to int truncates toward zero, so i = 3.
3. Signed types represent negative and nonnegative values; unsigned types represent only nonnegative values and arithmetic wraps modulo 2^N. With 8-bit unsigned char, c = 255.
4. i = 0, because 42 converts to true in the if condition.
